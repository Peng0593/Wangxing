# 汪星联络员

## 项目介绍

汪星联络员是一个基于AIGC技术的宠物AI写真生成工具，专为宠物主人提供服务，特别是那些失去宠物的主人。用户可以上传宠物的照片，输入自己想看到的内容文字，软件会自动分析需求并生成图片和视频，帮助用户创造美好的回忆。

## 核心功能

- **宠物照片上传**：支持上传宠物的照片，作为生成内容的参考
- **需求文字输入**：用户可以描述希望生成的内容，例如宠物在汪星的生活场景
- **AI图片生成**：利用AIGC技术生成符合用户需求的宠物图片
- **AI视频生成**：利用AIGC技术生成符合用户需求的宠物视频
- **结果展示和下载**：展示生成的图片和视频，并支持下载

## 技术架构

- **前端**：React + Vite + Axios
- **后端**：Node.js + Express + Multer
- **数据库**：MongoDB（可选）
- **AIGC API**：Stable Diffusion API（免费）

## 部署步骤

### 1. 后端部署

1. 进入后端目录
   ```bash
   cd backend
   ```

2. 安装依赖
   ```bash
   npm install
   ```

3. 配置环境变量
   - 复制 `.env` 文件并修改其中的 API 密钥
   - 替换 `STABILITY_API_KEY` 为你的 Stable Diffusion API 密钥

4. 启动后端服务
   ```bash
   npm start
   # 或使用开发模式
   npm run dev
   ```

### 2. 前端部署

1. 进入前端目录
   ```bash
   cd frontend
   ```

2. 安装依赖
   ```bash
   npm install
   ```

3. 启动前端服务
   ```bash
   npm run dev
   ```

4. 构建生产版本（可选）
   ```bash
   npm run build
   ```

## 使用指南

1. **上传宠物照片**：点击「选择文件」按钮，上传宠物的照片
2. **输入生成需求**：在文本框中描述希望生成的内容，例如：
   - "在汪星的草地上奔跑的金毛犬，阳光明媚，周围有花朵"
   - "穿着天使翅膀的猫咪，在云端玩耍"
3. **生成图片**：点击「生成图片」按钮，等待图片生成
4. **生成视频**：点击「生成视频」按钮，等待视频生成
5. **下载结果**：点击「下载图片」或「下载视频」按钮，保存生成的内容

## 注意事项

- 上传的照片最好是清晰的宠物正面照，这样生成的效果会更好
- 生成需求描述越详细，生成的内容越符合预期
- 由于使用的是免费的AIGC API，生成速度可能会受到限制
- 视频生成功能目前是模拟实现，实际项目中需要使用真实的视频生成API
